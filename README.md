# 📌 Overview

The **Automatic Car Parking System** is a smart automation project developed using **Python** and **OpenCV** for real-time parking management and vehicle detection.

This project helps in:
- ✅ Detecting vehicles
- ✅ Identifying empty parking slots
- ✅ Monitoring parking areas in real time
- ✅ Improving parking efficiency

The system demonstrates the implementation of **Computer Vision**, **Automation**, and **Real-Time Image Processing** concepts.

---

# ✨ Features

- 🚘 Automatic vehicle detection
- 🅿️ Parking slot identification
- 📷 Real-time camera monitoring
- ✅ Empty slot detection
- ❌ Occupied slot detection
- ⚡ Fast image processing
- 💻 User-friendly implementation

```text
        ↓
🧠 Image Processing
        ↓

        ↓

        ↓
✅ Empty Slot Detection
        ↓
💻 Output Display
```

---

# 🔍 Working Principle

The system continuously monitors the parking area using a live camera feed.

### Process:
- 📸 Capture parking area image/video
- 🧠 Process image using OpenCV
- 🚘 Detect vehicles
- 🅿️ Identify parking slots
- ✅ Detect empty spaces
- 📊 Display parking availability

# 📥 Installation

## 🔹 Clone Repository

```bash
git clone https://github.com/Monishpv/Automatic_car_parking.git
cd Automatic_car_parking
```

## 🔹 Install Dependencies

```bash
pip install opencv-python numpy
```

## 🔹 Run the Project

```bash
python main.py
```
